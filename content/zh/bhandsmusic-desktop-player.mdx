想安静听首歌，得先关掉两个弹窗、跳过三块推荐位。

所以我干脆自己做了一个。

**BhandsMusic** 是一个 Windows 桌面音乐播放器。它想做的事很朴素：打开就是歌，画面跟着音乐长。

![BhandsMusic 首页：左侧每日推荐，右侧是歌单、每日推荐、继续听、听歌画像与各榜单入口](/blog/bhandsmusic/home.jpg)

首页把「现在听什么」摊开成一张卡片网格——我的歌单、每日推荐、继续听、听歌画像，下面接各榜单。顶部只有一条搜索框，没有信息流。

## 一、播放时，界面本身是演出的一部分

播放态一共 **18 个视觉预设**，全部由 GLSL 粒子着色器实时驱动，跟着节拍与频谱一起呼吸。右键唤出「视觉控制台」就能切换、搜索、收藏，参数还能存成自己的存档。

比如**星球**——粒子聚成一颗缓慢自转的球体，低频一来整颗星球跟着脉动：

**星河**，把频谱拉成一条流动的星带：

![星河：频谱被拉成流动的星带](/blog/bhandsmusic/galaxy.jpg)

歌词也不是贴上去的一行字，而是有自己的 3D 舞台；另外还有独立的**桌面歌词窗口**和**壁纸模式**。

## 二、曲库：用四种音源兜住

一个自己做的播放器，最难的不是界面，是「点了有歌放」。

所以播放器里接了解析层，四种来源兜底：

| 音源 | 说明 |
|---|---|
| GD 音乐台 | 第三方聚合 |
| UnblockNeteaseMusic | 网易云补全 |
| LX Music 脚本 | 用户脚本，在**沙盒**里执行 |
| 自定义 API | 自己填接口 |

在这之上又做了几件事：

- **智能选择**：VIP / SVIP 账号优先走官方音源拿高质量，普通账号优先走第三方免费音源
- **音质自动降级**：优先 flac，拿不到就降 320k，再不行 128k，而不是直接报错
- **换源匹配**：切源之后校验时长等特征，防「货不对版」——搜到的是一首歌，放出来是另一首

另外还有一个我挺喜欢的：接 **Open-Meteo** 做天气电台，按你所在城市和当前天气 mood 生成播放队列。下雨天和晴天的队列不该一样。

## 三、真正吃掉时间的那 90%

视觉是那 10%。剩下 90% 的时间花在了一些截图上看不见的地方。

### 把 2.8 万行的渲染层拆开

渲染层原本是一个巨型单文件：满屏全局 `var`，靠跨 `<script>` 的函数提升串起来——动一行，不知道会炸在哪儿。

现在按职责拆成 **19 个文件**（`00-prelude.js` 到 `18-session-boot.js`），`public/js/app/` 一共 **28,676 行**。其中 `00-prelude.js` 是跨 script 函数提升的垫片，**必须排第一**。

拆这种东西最怕「看起来没事」。所以配了两道闸门：

- `check-app-hoisting.js` —— 校验跨 script 的函数提升依赖
- `check-app-reorg.js` —— 校验加载期读写顺序等价

两个都用 esprima 做 AST 扫描，而不是靠肉眼看 diff。UI 类的东西还有一批离屏 Electron 探针（取景、歌词、关闭对话框圆角都有专门的 probe）。

### 更新系统

从「检测到新版本」到「装完能用」，中间全是坑：

- **下载竞速选线**：多线路同时起跑，谁先到用谁，超时自动切
- **系统代理感知**：跟着系统代理走
- **装完自动清理**：不留安装包残骸
- 启动就检测到更新时自动弹出下载界面；changelog 首条不再重复显示

### QQ 登录的 SSL 刷屏

证书校验收紧之后，握手失败的日志会疯狂刷屏——刷到正常的错误都看不见。

我的处理是把校验策略收敛到该严格的地方，而不是图省事直接关掉校验。同一批里还修了 QQ 榜单的解析链，把榜单全量接了进来。

### 登出之后的边界状态

登出后播放 UI 要全归零、网易云的掉登录状态要跟本地对齐。这类「边界状态」最容易漏——功能测试时根本不会走到。

## 四、跑起来

```bash
npm install
npm start          # 开发运行
npm run build:win  # 打包 Windows NSIS 安装包，产物在 dist/
```

桌面端入口是 Electron 主进程加载本地服务。安装包走 GitHub Releases，支持增量补丁和完整包，多线路自动切换。

当前版本 **v2.2.0**。
