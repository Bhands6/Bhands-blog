写代码的人都有这个毛病：一坐下就是三小时，站起来的时候脖子是硬的，眼睛是干的，水杯还是满的。

市面上的健康 App 我试过几个，共同点是——**它想管的事比我想让它管的事多**。要打卡、要签到、要排行榜、要给我算"健康分"。

我只想要一个安静待在屏幕角落、到点提醒一下的小东西。所以自己写了一个。

**健康提醒助手**，Python + PyQt5，Windows 桌面悬浮窗，目前 **V 3.2**。

## 一、它长什么样

![从左到右：完整模式悬浮窗、迷你模式悬浮球、提醒弹窗、右键菜单](/blog/health-reminder/ui-chrome.png)

四个部件，都是很朴素的东西：

| 部件 | 干什么 |
|---|---|
| **悬浮窗** | 显示当前倒计时（比如「护眼提醒 00:49」）和今日已完成次数 |
| **悬浮球** | 迷你模式，一圈进度环，鼠标滚轮可以直接改大小 |
| **提醒弹窗** | 到点了弹出来，渐变背景 + 淡入，「知道了」或「延迟 5 分钟」 |
| **右键菜单** | 暂停、切迷你模式、改祝福数量、今日统计、设置、退出 |

操作就四个：**单击**弹满屏祝福、**双击**开设置、**右键**出菜单、**拖拽**换位置。

内置三类提醒：护眼 20 分钟、休息 45 分钟、喝水 30 分钟。另外可以自己加，图标有 21 个可选，间隔独立设。

## 二、最"没用"但最讨喜的功能

单击悬浮球，会弹出**满屏的祝福**。

迷你模式下，这些窗口**会排成一个心形**：

![上百个祝福窗口在桌面上排成心形，中间压着一张「万事顺意」](/blog/health-reminder/warm-tips-heart.jpg)

完整模式下就是随机撒满屏幕：

![同样的祝福窗口在完整模式下随机散布在桌面上](/blog/health-reminder/warm-tips-scatter.jpg)

窗口数量可调，**10 到 500 个**。每个窗口写着随机的短句：「辛苦了」「别熬夜」「记得吃水果」「天冷了，多穿衣服」「今天过得开心嘛」。按空格键或者点任意一个窗口，全部关掉。

爱心排列的实现其实就是一条很老的参数方程：

```python
for i in range(num_points):
    t = 2 * math.pi * i / num_points
    x0 = 16 * math.sin(t) ** 3
    y0 = (13 * math.cos(t) - 5 * math.cos(2 * t)
          - 2 * math.cos(3 * t) - math.cos(4 * t))
```

把 `t` 从 0 到 2π 均匀取点，就得到心形的轮廓点。再归一化、映射到屏幕的可用区域：

```python
nx = (x0 - min_x) / span_x
ny = (y0 - min_y) / span_y
px = margin_x + nx * usable_w
py = margin_y + (1 - ny) * usable_h   # y 轴翻转
```

两件事值得说：

1. **`1 - ny` 这个翻转不能忘**——屏幕坐标 y 轴向下，数学坐标向上，不翻转得到的是倒过来的心。
2. **去重**。窗口是有宽高的，不同 `t` 可能映射到同一个像素坐标，直接堆叠会出现"某些位置糊成一坨、某些位置是空的"。加一个 `seen_points` 集合过滤掉重复点。

## 三、设置面板：按设计稿重做的那一轮

V3.0 到 V3.2 之间，我把设置面板整个重做了一遍——深色渐变卡片风，配了步进器（`− 20 分钟 +`）、拨动开关、渐变色双色块。

![重做后的设置面板：深色渐变卡片、步进器、开关与渐变色选择](/blog/health-reminder/settings-panel.png)

重做过程中我在本地攒了十几个版本的预览图：深色版、浅色版、动态背景版、圆角版、标题放大版、标题居中版、独立胶囊按钮版……

然后**顺手也把提醒弹窗改了一版，改完自己看着觉得难看，直接回退了**：

```
revert(ui): 提醒弹窗恢复原版样式（新设计被否决：太难看）
```

所以最终只有设置面板是重做的，弹窗还是原来的样子。

这事我后来想明白了：**"更现代的设计语言"和"更好看"是两件不同的事**。设置面板那种信息密度高的界面，用卡片+分区能理清楚层级；但弹窗就一句话加一个按钮，套上同一套设计语言反而显得笨重——它没有需要被"组织"的信息。

设计稿给的是语言，不是答案。哪个界面该用、哪个界面不该用，还是得看它自己长什么样。

## 四、真正花时间的三个坑

功能列表看起来很平，但下面这几个坑一个比一个耗时间。

### 1. 打包成 exe 之后，设置全丢了

本地跑 `python main.py` 一切正常，打包成 exe 之后——**改过的设置重启就没了**。

原因：PyInstaller 打包的程序运行时会被解压到一个临时目录（`sys._MEIPASS`），程序一退出这个目录就被清掉。你把 `config.json` 写在那儿，下次打开当然什么都没有。

解法不是"全部改成 exe 目录"，而是**把路径分成两类**——只读的资源和可写的数据，本来就该放在不同的地方：

```python
if getattr(sys, "frozen", False):
    # 打包后：只读资源跟着临时解压目录（放这儿没问题，反正不改）
    RESOURCE_DIR = getattr(
        sys, "_MEIPASS", os.path.dirname(os.path.abspath(sys.executable))
    )
    # 可写数据跟着 exe 自己，才能活过下一次启动
    DATA_ROOT = os.path.dirname(os.path.abspath(sys.executable))
else:
    RESOURCE_DIR = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
    DATA_ROOT = RESOURCE_DIR

DATA_DIR = os.path.join(DATA_ROOT, "data")
CONFIG_FILE = os.path.join(DATA_DIR, "config.json")
STATS_FILE = os.path.join(DATA_DIR, "stats.json")
```

图标这类只读资源走 `RESOURCE_DIR`，配置、统计、日志走 `DATA_ROOT`。现在配置写在 exe 同级的 `data/` 里，日志写 `logs/`，重启后都还在。

分成两类不只是洁癖：**只读资源必须跟着发布包走，可写数据必须跟着用户走**。混在一起的后果，要么是配置被清掉，要么是每次发版都得把资源重新塞一遍。

顺便一提，这类问题**开发阶段永远不会暴露**——你必须真的打包一次、跑起来、改设置、关掉、再打开，才会发现。

### 2. 全局热键会被别的程序抢走

四个快捷键（`Ctrl+Shift+P/S/M/Q`）在 Windows 下走的是 `RegisterHotKey`，好处是悬浮窗没有焦点的时候也生效。

但 `RegisterHotKey` 会**注册失败**——如果这个组合已经被别的软件占了。直接报错退出肯定不行，所以做了降级：注册失败就退回窗口级快捷键，功能照常，只是需要窗口有焦点。

失败是正常路径的一部分，不是异常。

### 3. PyQt5 的参数类型很较真

画一张圆角卡片的时候撞上过这个：

```
TypeError: arguments did not match any overloaded call:
  drawRoundedRect(...): argument 2 has unexpected type 'float'
```

`QPainter.drawRoundedRect` 有一堆重载，接受的组合是 `(QRectF, float, float)` 或 `(QRect, int, int)` 之类。我传进去的是 `QRect` 配 `float` 半径——两边不匹配，Qt 直接拒绝。

顺带 `card.height()` 返回的是 int，但参与运算之后可能变成 float，最后传进去类型就错了。显式 `int()` 包一层就好。

Python 是动态类型，但 Qt 的 C++ 重载解析**在运行时按确切类型挑**，所以这类错误只能在跑的时候撞出来。

## 五、还有一堆小东西

- **勿扰模式**：设一个时段（比如 22:00–08:00），期间不打扰，迷你球上显示 💤
- **今日统计**：每天触发了多少次、完成了多少次
- **开机自启动**：写 Windows 注册表
- **系统托盘**：最小化后驻留后台
- **主题**：亮色 / 暗色切换，渐变起始色和结束色都能自己调
- **提示音**：不同提醒类型用不同音效（Windows 下用内置 `winsound`，不需要额外依赖）

整个项目的依赖只有两个：**PyQt5** 和 **plyer**。

## 七、跑起来

```bash
git clone https://github.com/Bhands6/Health-reminder.git
cd Health-reminder
pip install -r requirements.txt
python main.py
```

打成 exe：

```bash
pip install pyinstaller
pyinstaller 健康提醒.spec
```

源码 3000 行出头，分在 `src/ui/` 下几个文件里：悬浮窗、设置、弹窗、温馨提醒、自定义控件各一个。
